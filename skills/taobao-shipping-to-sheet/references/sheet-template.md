# Shipping Sheet Template

Use this layout when duplicating or recreating the Taobao shipping sheet.

## Header structure

- Row 1: title in cell `B1`
- Row 2 headers:
  - `B2` = `店铺名`
  - `C2` = `订单号`
  - `D2` = `快递`
  - `E2` = `快递单号`
  - `F2` = `签收状态`
  - `G2` = `商品明细`
  - `H2` = `备注`

## Data rows

Start data at row `3`.

- `A` = running index
- `B` = shop name
- `C` = order id
- `D` = carrier
- `E` = tracking number
- `F` = order status or logistics status
- `G` = joined purchased item description
- `H` = optional notes

## Example title

- `B1` = `Jihan Gao 4月中海运`

Use the same shape even when the title changes.
